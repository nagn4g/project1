- App: Jon's MCP client (Node.js, custom minimal Streamable-HTTP client), version 1.0. Model: muse-spark-1.3. The client calls Silvertongue's MCP server directly at https://mcp.silvertongue.dev/mcp?ref=frantic-mcp-1&receipt=1 (initialize, then tools/call).
- Voice: Gordon Ramsay (voice_id gordon-ramsay@sha256:75d1f9dd9d91c6507917eb4f50abd7c151658a95101391a9812be3d8849173f6). Asked for: a short WhatsApp reply declining a Friday dinner invitation, full intensity, full edge, no emoji, voice spelling. The exact ask to the AI was: "Use Silvertongue to write my reply as Gordon Ramsay: I can't make it Friday."
- Draft exactly as written:
  > Can't make Friday — I'm up to my elbows in orders and I refuse to serve you a half-baked evening. Give me a proper heads-up next time and I'll cook you something worth the wait. Deal, yeah?
- Score: 7/10 for sounding like Gordon Ramsay. The food imagery ("up to my elbows in orders", "half-baked evening"), the blunt decline, the order wrapped in a tag question ("Deal, yeah?"), and the warm fix at the end all read like him. It loses points because a written WhatsApp reply can't carry his spoken timing — the escalation and the shouted capitals don't land the same on a phone screen — and the "warm to the person" side softens the roast more than his TV tirades do.
- Finding: the get_voice_packet call rejects values that look reasonable but aren't in its enum — format "message", platform "chat", intensity "medium", edge "medium", emoji "none", spelling "us" all failed validation. The accepted values are format post/reply/explanation/thread, platform x/threads/bluesky/linkedin/instagram/facebook/reddit/youtube/email/slack/discord/whatsapp/github/generic, intensity light/full, edge clean/full, emoji on/off, spelling voice/tidy. I had to retry with reply/whatsapp/full/full/off/voice before the packet came back. Nothing else confused me; the receipt link appeared in the packet response on the first successful call.
- Change I would make: add the accepted enum values to the tool description itself (or return them in the validation error in a friendlier form). The error already lists them, but a first-time caller has to guess the shape; one example call in the description would remove the retry round-trip.
